# 📋 לוח פרויקטים (בסגנון Monday)

אפליקציה לניהול פרויקטים שרצה ישירות בדפדפן, בלי שרת ובלי התקנה.

## מה יש בה
- **כמה לוחות**: יוצרים, משנים שם ומוחקים
- **קבוצות**: מוסיפים, מקפלים, משנים שם וצבע
- **משימות** עם אחראי, סטטוס, עדיפות, תאריך יעד ופס התקדמות
- **תצוגת טבלה, תצוגת קנבן ותצוגת סיכום** (דשבורד)
- **גרירה**: מזיזים משימות בין קבוצות, או בין סטטוסים בקנבן
- **חלון פריט** עם הערות, תתי-משימות ועדכונים
- **חיפוש וסינון** לפי אחראי
- **ניהול אנשי צוות**
- **ייצוא וייבוא** של הנתונים כקובץ JSON (לגיבוי או להעברה בין מחשבים)

> הנתונים נשמרים בדפדפן שלך (localStorage). כדי להעביר אותם למחשב אחר משתמשים ב"ייצוא" ו"ייבוא".

## איך משנים את התוכנה ישירות באתר GitHub
1. פותחים את הקובץ שרוצים לשנות ולוחצים על סמל העיפרון ✏️ (Edit).
2. עורכים, ואז לוחצים על **Commit changes**.
3. אחרי דקה בערך האתר מתעדכן.

טיפ: אם לוחצים על המקש `.` (נקודה) בדף הראשי של המאגר, נפתח עורך קוד מלא בתוך הדפדפן.

### איזה קובץ עושה מה
| קובץ | מה יש בו |
|------|----------|
| `config.js` | **הכי קל לשנות**: שמות הסטטוסים וצבעיהם, העדיפויות, צבעי הקבוצות ואנשי הצוות |
| `style.css` | עיצוב: צבעים, גדלים וגופנים (הצבעים הראשיים נמצאים בראש הקובץ) |
| `index.html` | מבנה הדף |
| `app.js` | כל הלוגיקה של האפליקציה |

## הפעלת האתר (GitHub Pages)
1. נכנסים ל-**Settings**, ואז ל-**Pages**.
2. תחת **Branch** בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
3. אחרי דקה או שתיים האתר יהיה זמין בכתובת:
   `https://<שם-המשתמש>.github.io/<שם-המאגר>/`
